# UltrafastPhotoCurrentSpectroscopy
The git repo for my master thesis on ultrafast photocurrent spectroscopy.

## Contents
- **ThesisNotes**: A collection of paper summaries and notes on the theory and construction of the experimental setup.
- **papers**: A collection of papers relevant to the project.
- **Documentation** A collection of doc files from our equipment.
- **Simulations** Simulation in C/C++ of model systems.
- **ExperimentalControlCode** A repository of the Python control code for the experiment and data acquisition.

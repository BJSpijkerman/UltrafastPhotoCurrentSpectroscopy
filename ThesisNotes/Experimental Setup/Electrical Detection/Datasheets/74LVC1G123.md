The 74LVC1G123 is a single retriggerable monostable multivibrator with Schmitt-trigger inputs. It generates an output pulse on pin $Q$ with a duration dictated by an external resistor ($R_{\text{EXT}}$) and capacitor ($C_{\text{EXT}}$).

- __Operating voltage__: $1.65-5.5\,\text{V}$.
- __Input Voltage Tolerances__: Inputs accept up to $5.5\,\text{V}$.
- __Schmitt-Trigger Inputs__: All inputs ($\overline{A},\;B\;\overline{CLR}$) have Schmitt triggers for noise immunity and tolerance to slow signal transition times.
- __Drive Capability__: $\pm24\,\text{mA}$ output drive at $V_{\text{CC}}=3.0\,\text{V}$.
- __Power Down Protection__: Disables outputs when powered off ($V_{\text{CC}}=0\,\text{V}$),  preventing backflow current.

### Pin Configuration & Functionality

| **Pin** | **Symbol**              | **Description**                                        |
| ------- | ----------------------- | ------------------------------------------------------ |
| **1**   | $\bar{A}$               | Active LOW (negative-edge triggered) input.            |
| **2**   | $B$                     | Active HIGH (positive-edge triggered) input.           |
| **3**   | $\overline{\text{CLR}}$ | Active LOW direct reset and active HIGH trigger input. |
| **4**   | $\text{GND}$            | Ground ($0\text{ V}$).                                 |
| **5**   | $Q$                     | Active HIGH pulse output.                              |
| **6**   | $\text{CEXT}$           | External capacitor connection node.                    |
| **7**   | $\text{REXT/CEXT}$      | Junction node for external resistor and capacitor.     |
| **8**   | $V_{\text{CC}}$         | Supply voltage.                                        |

### Truth / Function Table

| Inputs                  |                |            | Output   | Behaviour                                             |
| ----------------------- | -------------- | ---------- | -------- | ----------------------------------------------------- |
| $\overline{\text{CLR}}$ | $\overline{A}$ | $B$        | $Q$      |                                                       |
| __L__                   | X              | X          | __L__    | Output reset / forced $\text{LOW}$                    |
| X                       | __H__          | X          | __L__    | Optput remains $\text{LOW}$                           |
| X                       | X              | __L__      | __L__    | Output remains $\text{LOW}$                           |
| __H__                   | __L__          | $\uparrow$ | $\Omega$ | Triggered on positive edge of $B$                     |
| __H__                   | $\downarrow$   | __H__      | $\Omega$ | Triggered on negative edge of $\overline{A}$          |
| $\uparrow$              | __L__          | __H__      | $\Omega$ | Triggered on positive edge of $\overline{\text{CLR}}$ |
Note: $\uparrow$ = LOW-to-HIGH transition, $\downarrow$ = HIGH-to-LOW transition, $\Omega$ = output pulse generated.


#### Output pulse width calculation
The pulse width generated at pin $Q$ using $R_{\text{EXT}}$ and $C_{\text{EXT}}$ connected between $V_{\text{CC}}$, pin $6$ and pin $7$.
$$
t_{\text{W}}=KR_{\text{EXT}}C_{\text{EXT}},
$$
where $t_{\text{W}}$ is the pulse width in $\text{ns}$, $R_{\text{EXT}}$ the resistance in $\text{k}\Omega$, $C_{\text{EXT}}$ the capacitance in $\text{pF}$ and $K$ a pulse factor constant ($K\approx1.0$, varying slightly depending on $V_{\text{CC}}$ and capacitance).

#### Retriggering & Reset Modes
- __Retriggering__: If a new trigger pulse arrives at $\bar{A}$ or $B$ before $t_{\text{W}}$, the internal timing restarts. Continuously re-triggering drives $Q$ $\text{HIGH}$ for up to a duty cycle of $100\%$.
- __Direct Reset__: Driving $\overline{CLR}$ $\text{LOW}$ at any time aborts the pulse and forces $Q$ $\text{LOW}$.
